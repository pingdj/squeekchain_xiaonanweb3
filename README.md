# Squeekchain Health Monitor

A comprehensive, real-time health monitoring dashboard and portfolio viewer for the Squeekchain ecosystem on Sepolia.

## 🔗 Live Demo
**[View Live Dashboard](https://www.ming.store/tool/squeekchain/)** *

## 🌟 Key Features
- **Wheel Live:** Real-time hamster wheel telemetry (RPM, speed, distance) with dynamic CSS-based animation matching actual chain data.
- **Core & Settlement Lag:** Tracks Squeek blocks, difficulty, and live settlement latency with sentiment-based UI indicators.
- **SQK Economy:** Visualizes supply progress, minted SQK, tier levels, and the complete merge pyramid.
- **Staking & Yield Estimator:** Displays live staking pool data and includes a What-If calculator for daily SQK yield estimation based on network power.
- **Event Feed:** Live categorized event stream with one-click address tracing to view any player's portfolio instantly.
- **Portfolio Viewer:** Query any Sepolia address to view claimable SQK, active NFT power, and detailed Squeek positions (including secure isolated SVG rendering).

## 🛠️ Tech Stack
- **Vanilla HTML / CSS / JavaScript** (Zero frameworks, no build step)
- **Chart.js** for data visualization
- Fetches live data directly from the official `api.squeekchain.com/v1`
- Fully responsive, dark-themed, and optimized for readability.
